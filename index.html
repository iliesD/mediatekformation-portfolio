Mediatek86

Contexte

MediaTek86 est un réseau clé dans la gestion des bibliothèques du département de la Vienne, assurant la circulation des livres, DVD, et CD parmi les diverses bibliothèques, tout en se focalisant sur le développement de ressources numériques accessibles à tous. Avec l'ambition d'enrichir l'expérience proposée aux utilisateurs, MediaTek86 souhaite diversifier ses offres en introduisant des formations dédiées aux outils numériques pour ses membres, et en mettant à disposition des ressources d'auto-apprentissage en ligne. Cette initiative a mené à la création du site Mediatek Formation, marquant un pas en avant dans la stratégie de modernisation et d'élargissement des services de MediaTek86.

Outils et langages utilisés :

  • IDE : Vscode
  • Langages : PHP et Twig
  • SGBD : MySQL
  • Serveur Web : Symfony CLI (local), Wamp (local)
  • Framework : Symfony
  • Serveur d'authentification : Keycloak
  • Machine virtuelle : Debian, Windows 10
  • Versionning : Github

Objectif :

Je reprends le flambeau sur le projet de développement de l'application pour "Mediatek Formation". Mon rôle consiste à perfectionner le code existant, finaliser le back-office, et orchestrer le déploiement. Une tâche cruciale sera d'intégrer un mécanisme d'authentification externe via Keycloak. Les directives et les exigences s pécifiques du projet sont détaillées dans un cahier des charges fourni. Le développement s'appuie sur la version 5.4 de Symfony.
